## Умова завдання (Варіант 5)
Обчислити значення кусково-неперервної функції $y(x)$:
- $y = x^3 - 6$, якщо $x \in (-10, -5] \cup (5, 15]$
- $y = 2x^3 - 3x + 2$, якщо $x \in [25, +\infty)$
- **не визначена** в інших випадках
